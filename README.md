## Projects

### FM Radio Receiver *(In Progress — ECE299 Capstone)*
Designing a full FM radio receiver from the ground up. Custom PCB layout in KiCAD around an RDA5807M tuner IC, with embedded firmware written in C for tuner control and user interface.

`KiCAD` `C` `Microcontroller` `PCB Design`

---

### Pattern Recognition Game
A Simon-style sequence memory game built two ways: a custom-etched and soldered PCB console with a microcontroller, LEDs, and tactile buttons, and a fully playable browser version written in JavaScript.

`Python` `PyGame` `JavaScript` `PCB Etching` `Soldering`

---

### Sorting Algorithm Visualizer
Visualizes six sorting algorithms in real time using color-coded bars and an audio feedback system that maps array values to pitches, giving simultaneous visual and auditory feedback of each comparison and swap. Playable in the browser.

`Python` `PyGame` `Algorithm Design` `Data Visualization`

---

### Curve Plotter
A C++ application using SDL3 that plots an implicit curve defined by a function of x and y, tracks the nearest point to the cursor, and renders the tangent line in real time. Compiled to WebAssembly and embedded live on the site.

`C++` `SDL3` `WebAssembly` `Emscripten`

---

### Air Compressor Flywheel
Designed a pneumatic flywheel engine in SolidWorks, including full part modeling, assembly constraints, and motion study simulation, then machined all components to tolerance on a metal lathe, mill, and drill press. Achieved the highest RPM of the class cohort at **6,378 RPM**.

`SolidWorks` `Metal Lathe` `Mill` `Drill Press` `CAD/CAM`
